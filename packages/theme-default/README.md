# @entirius/theme-default

The default theme of the Entirius storefront: every part of the shop's look, from the product card to the account
pages, and the UI elements (shadcn/ui) they are made of. A theme replaces any file by putting its own at the same
path; everything else comes from here.

`pnpm overrides` in a theme lists what can be replaced, by where it shows in the shop; `pnpm eject <path>` copies a
file to start from.

- [The theme contract](https://github.com/entirius/entirius-pwa-storefront/blob/develop/docs/themes/contract.md)
