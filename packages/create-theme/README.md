# @entirius/create-theme

Starts a theme for the Entirius storefront:

```bash
pnpm create @entirius/theme my-theme             # a theme that overrides nothing yet
pnpm create @entirius/theme my-theme --example   # a theme with a look of its own to start from
```

[Building a theme](https://github.com/entirius/entirius-pwa-storefront/blob/develop/docs/themes/guide.md) goes on from there.
